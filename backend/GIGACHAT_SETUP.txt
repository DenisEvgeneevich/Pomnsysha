Настройка GigaChat API
=====================

Для работы ИИ помощника необходимо настроить авторизацию GigaChat.

Шаги настройки:
1. Перейдите на https://developers.sber.ru/studio/workspaces/gigachat
2. Зарегистрируйтесь и получите API ключ авторизации
3. Создайте файл .env в директории backend со следующим содержимым:

GIGACHAT_AUTHORIZATION_KEY=ваш_ключ_авторизации_здесь

4. Перезапустите сервер

Пример:
GIGACHAT_AUTHORIZATION_KEY=ABC123...xyz789
